# 2028 高考弹性学习计划 · 循序

面向在职备考者的中文学习计划网站，使用 Vue 3、TypeScript 和 Vite。黑白配色，支持浅色、深色与系统主题，适配手机和电脑。

## 页面与计划

- 学习概览：本周实际学习、打卡进度与预计考试倒计时。
- 分月路线：2026 年 10 月至 2028 年 6 月，共 21 个月；阶段可筛选。
- 六科学习路径：语文、数学、英语、物理、化学与待确认第三科。
- 首四周任务：摸底、修补、学练循环与复测，单独保存打卡。
- 每周任务：每周独立记录任务、实际学习时长与建议配额。
- 设置与备份：第三科、预计日期、默认配额、主题及 JSON 导入导出。

第三科默认显示“待确认”，生物只是可更改参考，可切换地理或思想政治。切换后路径、周任务与分月内容更新，历史时长仍保留原科目名称。

| 周方案 | 数学 | 英语 | 物理 | 化学 | 语文 | 第三科 | 总计 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 常态 | 4 | 3 | 3 | 2.5 | 2 | 1.5 | 16 |
| 忙碌 | 2 | 1.5 | 1.5 | 1 | 1 | 1 | 8 |
| 加量 | 5 | 4 | 4 | 3.5 | 3 | 2.5 | 22 |

单位为小时，均为建议。复习、测验与订正已经包含在总量内。忙碌方案仅作应急；连续两周难以完成常态配额时按实际时间调整。按班表拼接 20、40、90 分钟任务块，月末预留约四分之一配额复测，不另加码。

## 开发与验证

使用 Node.js 24 和 npm。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run test:e2e
```

本地浏览器测试默认使用已安装的 Chrome。需要使用 Playwright Chromium 时：

```sh
npx playwright install chromium
```

将 `PLAYWRIGHT_CHANNEL` 环境变量设置为 `chromium` 后运行 `npm run test:e2e`。测试覆盖桌面及手机布局、双主题对比度、刷新保存、周隔离、重复操作、无效备份、覆盖确认与科目切换。截图在 `test-results/`，报告在 `playwright-report/`；这些本地验证文件不会提交到仓库。

测试默认在独立端口 `5188` 启动自己的服务器，端口已占用时直接报错，不复用其他应用。受限 Windows 环境若无法自动清理测试服务器，可先在单独终端运行 `npm run dev -- --port 5188 --strictPort`，仅在确认这是本项目后，将 `PLAYWRIGHT_EXTERNAL_SERVER` 设置为 `true` 再测试，最后停止自己启动的服务器。CI 默认自动管理服务器。

## GitHub Pages

采用 **GitHub Actions 部署**，不是分支部署。仓库根目录包含 `.github/workflows/pages.yml`。

1. 在现有仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 推送到 `main`，或在 Actions 中手动运行 **Deploy to GitHub Pages**。
3. 工作流安装依赖、运行单元测试、类型检查与构建、桌面/手机浏览器测试，再上传 `dist/` 并部署。

默认生产 base 为 `/study-plan-2028/`，对应项目 Pages 路径。开发环境 base 为 `/`。其他仓库名可通过 `VITE_BASE_PATH` 覆盖。站内使用 hash 导航，刷新子页面无需服务端重写。

构建输出可直接用于 Pages：`dist/index.html`、`dist/assets/` 与图标。使用 `npm run preview` 后访问终端地址下的 `/study-plan-2028/`。目标网址为 `https://pbsmart.github.io/study-plan-2028/`，是否已上线须以 GitHub 部署结果为准。

## 本地数据与备份

- 没有账号、服务端数据收集或分析埋点；无需 API 密钥。
- 所有用户记录保存在当前浏览器、当前来源的 `localStorage`，键为 `xunxu.gaokao.v1`。
- 任务勾选不增加时长；计时不自动保存，只有确认实际学习后才写入。切到后台自动暂停，刷新会丢弃未保存计时。
- 手动补录只允许所选周内、不晚于今天的日期；一天累计最多 24 小时。
- JSON 备份 v1 包含 `version`、`firstCompleted`、`settings`、`weeks`，限制 5 MB。校验字段、枚举、日期、周归属、唯一记录 ID、整数时长及每日总量，确认覆盖前不会更改现有记录。
- 更换浏览器、设备、域名或清理站点存储会影响记录；请定期导出。备份可能包含自己的学习信息，请自行保管，不要提交公开仓库。
- 官方资料链接仅在点击后打开外部网站；页面本身不加载第三方字体或统计脚本。

## 使用边界与内容维护

本计划是通用学习建议，不保证成绩或录取，不把历史分数作为未来保证线。诊断任务是自行选题指引，没有内置题库、智能评分、录取预测或等级赋分功能。默认预计考试日期 `2028-06-07` 仅供规划，考试日期及时段待官方公布。报考、选科、教材范围、体检及报名时间以当地当年官方发布为准。

历史参考：[郑州市教育局河南 2026 年报名问答](https://zzjy.zhengzhou.gov.cn/ptgzyjs/9673247.jhtml)、[阳光高考听力及计分历史资料](https://gaokao.chsi.com.cn/gkxx/zc/ss/202402/20240229/2293259554.html)。历史规则不能替代 2028 年通知。

通用教学内容集中在 `src/content.ts`；数据模型和校验在 `src/model.ts`；界面与样式分别在 `src/App.vue`、`src/style.css`。修改存储结构须同时更新版本、校验和测试。公开代码不得加入姓名、个人成绩、聊天记录、访问令牌或用户备份。
