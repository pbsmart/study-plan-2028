## 收听行为

仅在用户点击后播放；支持暂停、进度拖动、±15 秒、0.75/1/1.25/1.5/2 倍速和从头播放。未制作音频的课程明确显示“待制作”，不提供假播放。

每课记录保存在当前浏览器 `xunxu.podcast.v1`，含 position、rate、listened，与学习计划、打卡、学习时长、DeepSeek 配置完全独立。刷新后不会自动播放；听完不会自动下一课或标记掌握。当前计划备份不包含收听断点。存储不可用时提示保存失败，仍可播放。后台行为由浏览器音频策略决定，未申请后台运行权限。

## 替换完整音源

1. 使用新完整课覆盖同一路径，仅保留一个公开 MP3；不要提交样音、服务配置、模型缓存或本地路径。
2. 更新 `src/podcast/catalog.ts` 的版本、实际时长，更新 `src/podcast/transcript.ts` 的对应全文和本说明中的校验值。没有可靠时间标记时移除旧标记，不沿用旧同步信息。
3. 保留课程 ID 可保留收听历史；若教学内容发生实质变化，应明确迁移或重置策略。恢复进度会按实际音源长度截断。
4. 更新音源时长相关测试，运行单测、构建、bundle 检查与桌面/手机播客 E2E，然后通过现有 Pages workflow 发布；不需要改 workflow。
