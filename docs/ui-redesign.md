# 课程与逐题练习改版

基线：`b0b261df9280345ade2de70abc7878412c0fdf45`。以已批准的桌面/手机课程与练习设计为参考，使用真实题库和实际音频实现。

- 桌面为窄课程目录和连续正文；目录按准备、讲解、例题、独立练习、测评与订正分组。当前项用浅蓝底和蓝色细竖线，手机目录默认折叠。
- 周计划、课程选择、笔记与设置沿用同一排版和蓝色强调；重复统计折叠，去除宣传口号和大型展示卡片。
- 各题组一次显示一道题，保留全部原题、评分点、引文和关联图。切题关闭解析；例题、诊断与测评原有路由保持不变。
- 现有题目没有可安全通用自动评分的结构化选项/答案类型。开放计算、解释、论述和写作题采用独立作答后“检查答案”，显示原有参考答案与评分点，再由用户自评。不会按字符串相似度自动判对、判错或标记掌握。
- 作答框是临时草稿。需要长期保留的理解和错因可保存到“笔记与错因”，并在“笔记与错题”页按课程回看。
- 笔记使用独立的 `xunxu.notebook.v1`，最多500条、每条8000字符，独立导入/导出。计划 v1/v2、已有学习进度、打卡、时长、旧日志、音频断点和 DeepSeek Key 均不迁移或覆盖。待订正仅由用户手动标记，不是评分或掌握状态。
- “这一步没懂”按需打开原 AI 对话。Key、资料选择、发送预览、上下文预算、取消和历史管理保持原行为；笔记和作答草稿不会自动发送给 AI。
- Dylan/Serena完整MP3、单一音源、跨路由迷你播放器、进度拖动、倍速、断点和逐字稿保留。未制作音频的课程不显示课程播放器，听完不改打卡。

`tests/e2e/redesign.spec.ts` 验证响应式目录、逐题作答、自评、AI入口与笔记持久化。原全站课程、图、AI、进度和主题测试继续回归；旧黑白主题及折叠目录断言适配已批准的新设计。`ui-redesign-integrity.json` 只更新有意修改的展示/接入模块，课程内容、学习模型、AI传输/上下文、音频引擎和工作流保留原有完整性保护。
